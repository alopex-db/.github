# alopex-db/.github

Default community health files for the **Alopex DB** organization. GitHub falls
back to these for every repository in the org that does not define its own.

| File | Purpose |
| --- | --- |
| [`profile/README.md`](./profile/README.md) | The organization profile shown on <https://github.com/alopex-db> |
| [`.github/FUNDING.yml`](./.github/FUNDING.yml) | Default Sponsor button (GitHub Sponsors + Buy Me a Coffee) |
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | How to contribute, where each project is tracked, and what a PR needs |
| [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) | Contributor Covenant 2.1, with reporting route |
| [`SECURITY.md`](./SECURITY.md) | Private vulnerability reporting and supported versions |
| [`SUPPORT.md`](./SUPPORT.md) | Where to ask questions and file bugs |

Brand assets (logo mark, lockups, social cards, palette) live in
[`alopex-db.github.io`](https://github.com/alopex-db/alopex-db.github.io/tree/main/docs/assets/images/brand)
— see `BRAND.md` there before using them.

Documentation for the projects themselves lives at <https://alopex-db.github.io>.
